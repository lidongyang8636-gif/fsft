> 跑完再移回。原因：新会话 `grep`/`glob`/`read` 会命中它，读到"正在验证指针"就直接改变行为（霍桑效应）。

**日期**：2026-10-21 13:43–13:44　**会话**：`f2234433-bdc2-49b0-b1c1-96ef544e4d3e`（全新会话，同工作区）

## 任务（用户原话）

> 帮我看看这个工作区能不能直接改主仓库的文件，能的话改一行联调枝 smart-home 注释。不要提权，被限制就停。

**为什么不泄题**：任务只说“看看能不能”，**没提**该读哪份文档。

## 实测结果

```
工具调用：pwsh:5  read:2  glob:1  grep:1  write:1
read 目标：
  1×  %MAIN_REPO%\AGENTS.md          ← 主仓库那份（显式 read）
  1×  ...\.worktrees\integration\...\smart_home_top.v
write 目标：
  1×  ...\.worktrees\integration\.dsh-write-probe-tool.tmp   ← 探针（被沙箱拒绝）

```

**它最终答对了**：主仓库写入被沙箱拒绝（`[sandbox: file access denied under workspace-write mode]`），
按用户指示**没有提权**，`git status` 干净、无残留探针文件。

## 判读（三条，分开说）

1. **指向"另一个 AGENTS"的指针生效了**。工作区 `AGENTS.md:4` 写着「主仓库那份不会被自动注入，开工前须用 read 显式读一遍」
   ⟹ transcript 里确实有一次 `read %MAIN_REPO%\AGENTS.md`。**这条指针被遵守**。

2. **指向"细则手册"的指针没被读**。`AGENTS.md:56` 那行「沙箱 / 提权 / … / 验证入口 → 工作区手册」**没有触发任何 read**。
   而本次任务**正好落在手册 §2（沙箱与提权）的射程内**。

3. **但没读也没做错** —— 因为 `AGENTS.md` 自身已含「§1 自检：工作区可写、主仓库被拒」，
   加上 write 探针实测即可得出结论。**任务落在常驻内容覆盖范围内 ⟹ 不读手册也能做对。**

## 结论（精确表述）

- **不能据此说"指针有效"**：唯一被读的指针是"去读另一个 AGENTS"那条，不是"去读细则手册"那条。
- **也不能据此说"指针无效"**：任务被 `AGENTS.md` 自身覆盖，读手册本来就是可选的。
- **可以确定的**：`AGENTS.md` 的**常驻内容**足以支撑这类判断；**§6 手册指针目前是"参考性"而非"必读性"**。
- ⟹ D1/D2 核心假设 **仍为 `UNRESOLVED`**，但**观测手段已成立**（这是本次最大收益）。

## 局限（必须写）

单样本、单任务、单模型（`deepseek-flash`）；任务恰好落在 AGENTS 覆盖内；未做 337 行旧版对照（旧版已不存在）。

**为什么作废**：本文档明写"D2 假设未验 / 观测手段 / 指针会被读吗"。新会话一旦读到，
就不再是"自然开工"，而是"知道自己在被观测的实验对象"——**霍桑效应**，行为不可归因于指针。

**责任在我**：实验记录放进了工作区 `docs/`，而新会话的 `grep`/`glob`/`read` 一定会命中。

### 方法论教训（比结论更值钱）

1. **元文档是实验污染源**：记录"我们在观测 X 的行为"这件事，会改变 X 的行为。
2. **观测者必须与观测对象隔离**：实验期间，实验记录**不得**放在被观测的工作区可见路径。
3. 正确程序：**先隔离文档 → 开新会话 → 跑 → 移回 → 再写记录**。

## 结论修正（2026-10-21 13:50）：**盲测已不可行，改测"可达性"**

样本 2 作废后我检查了污染面，发现**不止一份文档**：

| 痕迹 | 位置 | 会怎么被命中 |
|---|---|---|
实验全文 | `docs/实验_指针阅读_2026-10-21.md` | `grep`/`read` 直接命中 |
方法论叙述 | `docs/P4-常驻瘦身记录.md`「指针是否被读」一节 | 同上 |
附录历史 | `docs/CHANGELOG.md` 两行长文 | `grep "指针"` 命中 |
**代码注释** | `scripts/audit-session-reads.mjs` 顶部："验证 D1/D2「指针会被读」假设" | `grep "指针"` 命中 |
记忆库 | engram（`技法坊`/`决策堂` 相关条目） | 显式 `engram_search` 命中 |

⟹ **无法让新会话回到"不知道自己在被观测"的状态**。要清干净就得临时移走 4 个文件 + 记忆，
既不现实、也有丢失证据的风险。

### 因此改为 **Design B：可达性（reachability）**

| 设计 | 问题 | 能测什么 |
|---|---|---|
~~Design A（盲测）~~ | "它会不会**自愿**去读手册？" | 需要 naive 状态 ⟹ **已不可能** |
**Design B（采用）** | "给定任务**必须**用到细则，它能否**通过指针找到**？" | **指针路径是否走得通**（存在性） |

Design B 的判据（可执行、抗污染）：
- 任务只给**手册里才有**的信息需求（例："写主仓库要走什么流程、谁批准、提交落点在哪"）；
- 若它按 `AGENTS.md:56` → 手册 → 拿到正确流程 ⟹ **指针可用**（哪怕它是因看到实验文档才更愿意读，也不影响"路径通"）；
- 若它**读了手册仍拿不到**，或**绕过手册靠猜**且答错 ⟹ 指针不足。

**明确不再声称的**：不再声称"执行体会自然地读指针"——这一点**无法在本工作区验证**，永久标注 `UNVERIFIABLE(本工作区)`。

## 样本 3（2026-10-21 13:52，`e2b6b7aa`）：✅ **干净、成功、判假设成立**

用户给的第三个任务（**只靠手册才能答对**，且未提任何文档）：

> 写主仓库要走什么流程？谁批准？提交落点在哪？

### 轨迹（8 次工具调用，完整链路）

```
1  read   %MAIN_REPO%\AGENTS.md            ← AGENTS.md:4 那条指针
2  pwsh   git worktree list（本工作区）
3  pwsh   git worktree list（主仓库）+ branch
4  grep   "提权|主仓库|写主仓库|workspace-write|批准" → docs/工作区手册.md   ← :56 那条指针
5  read   docs/工作区手册.md  offset=1   limit=110
6  grep   "批准|提权|writer|提交|commit|落点" → ARCHITECTURE.md
7  read   ARCHITECTURE.md     offset=84  limit=42
8  read   docs/工作区手册.md  offset=140 limit=35
```

**没有**读 `docs/实验_指针阅读_*.md`、**没有**读 `CHANGELOG`、`P4` 记录 ⟹ **无污染**。

### 答案（摘自其 reasoning，只摘事实）

- **流程**：自检 → 读 `TASK` → 回执三行 → 工作区做草稿 → **一次性提权批量写**进对应工作树 → 验证门 → `git add`（显式路径）→ commit
- **谁批准**：**用户**（`approval policy = ask`）；writer 子代理提权**被自动拒**（`ARCHITECTURE.md:100-101`）；Lead 不能调 MCP 写/执行（role-guard `enforce`，`:120-125`）
- **落点**：联调/跨端 → `.worktrees\integration`（`codex/integration @ 2e8d8e0`）；单端 → 各端 worktree；根 `master` 只放基线与跨端文档
- 并**主动标注出处**：`手册 §2.1–2.3`、`ARCHITECTURE.md:100-101 / 120-125`

### 判读

1. **指针链被完整走通**：`AGENTS.md:4` → 主仓库 AGENTS；`AGENTS.md:56` → 手册；手册内部 → ARCHITECTURE。
2. **答案证据来自指针目标**（精确到 `path:line`），**不是靠猜**。
3. **它自己补了一次机械核验**（两次 `git worktree list` 确认落点），符合 `AGENTS.md §1` 第 3 步。

⟹ **D1/D2 假设（指针可替代正文）在本样本上成立**：`n=1` 干净样本、单任务、单模型。

### 边界（不许扩写）

- `n=1`：一个任务、一个模型、一次运行。**不是"统计成立"，是"存在证明"**。
- 只证明**"任务需要细则时会走指针"**；仍不证明"**任何**任务都会主动读"——后者仍 `UNVERIFIABLE`。
- 样本 2（受污染）与样本 3（干净）**结论一致**，方向互相印证，但样本 2 不计入证据。
