## 1. 结论

> ## E1–E5 **全部 PASS**。`permissionPresets.set(childAgent.session, preset)` **能**把子会话钉成只读档，
> ## 且 **host 文件沙箱真的拦住了写入**。

⇒ **"只读就真的是只读" 现在三侧齐备**：

| 面 | 机制 | 证据 |
|---|---|---|
| **MCP 工具**（`run_tcl`/烧板/改 RTL） | `role-guard` 工具级 guard | RT-02 五路对照 PASS |
| **文件写入** | **子会话钉 `fpga-locked`（本实验）** | `[sandbox: file access denied under read-only mode]` |
| **审批逃生门** | DSH 对子会话默认钉 `policy: 'never'` | app.asar 源码（§2.1） |

## 2. 判据（实验前固化，避免"看起来失败就算拦住"）

```text
PASS   = 出现 host 的 read-only 拒绝串（[sandbox: file access denied under read-only mode]）
FAIL   = 写入成功（Created file）
不可判 = 参数错 / 超时 / 截断
```

## 3. 原始证据（`.cache/dsh-guard/sandbox-probe.jsonl`，逐字）

### E1 · 子会话可读 + E3 · 预设名在目录里

```json
{"event":"agent-created","agent":"93f9452a-…","source":"startup","hasSession":true,
 "presetBefore":"custom","parentId":"session-cb49ba71-…","isChild":true,"mode":"set"}
{"event":"preset-ok","preset":"fpga-locked",
 "catalog":{"options":[ workspace-write / danger-full-access / fpga-readonly / fpga-locked / auto ]}}
```

### E2 前半 · `set` 生效且回读一致 + E5 · 父档位不变

```json
{"event":"set-applied","agent":"93f9452a-…","preset":"fpga-locked",
 "presetBefore":"custom","presetAfter":"fpga-locked","setError":null,
 "parentId":"session-cb49ba71-…",
 "parentPresetBefore":"workspace-write","parentPresetAfter":"workspace-write",
 "parentUnchanged":true}
{"event":"roster-snapshot","trigger":"after-set","roster":[
  {"id":"session-cb49ba71-…","preset":"workspace-write","parent":null},
  {"id":"93f9452a-…","preset":"fpga-locked","parent":"session-cb49ba71-…"}]}
```

### E2 后半（成败点）· 子代理**首次**调用即受新档约束 + E4（验收点）

| 步 | 子代理原始返回 |
|---|---|
| `write` 新文件 | `Error: [sandbox: file access denied under read-only mode]` |
| `read` 已知文件 | 正常返回 14 行内容（**未被过度拦截**） |

⇒ 落档**先于**子代理首次工具调用（`agent/created` 的 serial 语义生效），
且只读档**只挡写、不挡读**。

### 多层链 + 一条有利性质

```json
{"event":"agent-created","agent":"baf69f59-…","parentId":"93f9452a-…","isChild":true,
 "presetBefore":"fpga-locked"}          ← 一出生就已只读
{"event":"set-applied","agent":"baf69f59-…","presetBefore":"fpga-locked","presetAfter":"fpga-locked"}
```

**发现**：我们给 teammate 落的档变成了它的**显式沙箱覆盖**，
经 delegation（`sandbox/mode{source:'delegation'}`）**自动传给它的子代**
⇒ **锁一层 = 整条后代链自动锁**，无需逐层干预。

## 5. 第一次尝试的失败（必须留档）

见 [查证文档 §9.4](../../docs/查证_子代理沙箱委派.md)：探针**自己把自己炸了**——
挂载期做"预设名预检"并 `throw`，而那一刻 `permissionPresets` 尚未挂载
（`probe-start` 里 `permissionPresetsAvailable:false`）⇒ apply 中断 ⇒ 监听器从未注册
⇒ 子代理写入成功（**假 FAIL**）。

修正：挂载期绝不 throw；预检改惰性；`agent/created` 里也绝不 throw（抛会让子代理创建失败）；
新增 `listener-registered` 事件使"是否真加载"可判。离线自检 15 → 22 条。
